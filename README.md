# FastAPI_MongoDB
Fast api todo app with mongodb

#steps:
s1. create virtual env... e.g.- venv
s2. install fastapi in venv == pip install fastapi uvicorn pymongo
s3. inside configurations. py > uri='' put your mongodb string
s4. for run the code===> uvicorn main:app
s5. go to http://127.0.0.1:800/docs and do any database manipulation.
