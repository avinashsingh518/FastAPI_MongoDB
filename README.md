# FastAPI_MongoDB
Fast api todo app with mongodb

#steps:
1. create virtual env... e.g.- venv
2. install fastapi in venv == pip install fastapi uvicorn pymongo
3. inside configurations. py > uri='' put your mongodb string
4. for run the code===> uvicorn main:app
5. go to http://127.0.0.1:800/docs and do any database manipulation.
